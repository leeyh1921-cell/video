# 남다른AI - Shorts 분석기

YouTube Shorts 및 비디오 분석 대시보드 웹 애플리케이션입니다.

## 🚀 실행 방법

### 로컬 실행
Node.js 내장 서버를 실행하여 로컬 환경에서 테스트할 수 있습니다:

```bash
node server.js
```

브라우저에서 `http://localhost:8000` 으로 접속합니다.

또는 `index.html` 파일을 직접 웹 브라우저로 열어서 사용할 수 있습니다.

## 📁 파일 구조
- `index.html`: 메인 웹 애플리케이션 (UI 및 분석 로직 포함)
- `server.js`: 정적 서빙용 경량 로컬 서버
